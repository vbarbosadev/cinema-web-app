# Cinema Web App

Aplicacao web estatica e romantica para registrar uma ida ao cinema e abrir por QR Code.

## Como editar o conteudo

Os textos, detalhes do encontro, fotos e linha do tempo ficam centralizados no objeto `memoria`, em `script.js`.

As fotos usadas na galeria ficam em `assets/images/`. A ordem atual esta definida em `script.js`:

- `carnaval.jpg`
- `louis-doc.jpg`
- `uf.jpg`
- `uf-2.jpg`
- `olho-no-olho.jpg`
- `hotel.jpg`
- `no-cinema-3.jpg`
- `no-cinema-3-l.jpg`

## Como abrir

Abra `index.html` diretamente no navegador ou publique a pasta em um servico estatico como GitHub Pages, Netlify ou Vercel. Depois de publicada, use a URL final para gerar o QR Code.
